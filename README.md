# 女性容姿評価プラットフォーム

写真を一枚ずつ表示して採点し、個人の評価傾向を集計するためのWebアプリケーションです。

## 主な機能

- 写真を順番に表示して採点
- 採点結果と平均点の集計
- 中国・日本・韓国の写真ライブラリ
- `Image_ckj` に追加した画像の自動同期
- 評価データのブラウザ内保存

## 起動方法

Node.jsをインストールした環境で、次のコマンドを実行します。

```powershell
pnpm install
pnpm dev
```

起動後、ブラウザで `http://localhost:3000` を開きます。

Windowsでは `start-rating.cmd` から起動することもできます。

## 注意事項

収録画像の権利は、それぞれの権利者および掲載元に帰属します。画像を再利用する場合は、各掲載元の利用条件を確認してください。
